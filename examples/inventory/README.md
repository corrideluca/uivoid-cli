# Demo: ask an agent what's running low

A tiny public API with three fictional products, two read operations, and no dependencies beyond Node.js 20+. Use it to try OpenAPI → UIvoid → your MCP client.

## 1. Run the API

From this repository's root:

```bash
node examples/inventory/server.mjs
```

In another terminal:

```bash
curl http://localhost:3000/products
curl http://localhost:3000/openapi.json
```

You should see notebooks (12 in stock), pencils (3), and backpacks (0).

## 2. Make it reachable

Deploy this folder to your Node.js host, using `node server.mjs` as the start command, or expose port 3000 through an HTTPS tunnel you control. The server honors `PORT` and binds to `0.0.0.0`. Keep it running for the demo.

Set `BASE_URL` to the resulting public HTTPS origin. Check that both `$BASE_URL/products` and `$BASE_URL/openapi.json` are reachable. A localhost URL alone will not work with the hosted gateway.

## 3. Create two MCP tools

With a UIvoid account and an owner/admin organization role, replace the base URL below and choose an available project name:

```bash
export BASE_URL='https://your-deployed-demo.example.com'
npx uivoid create inventory-demo \
  --base-url "$BASE_URL" \
  --include list_products,get_product
```

The CLI opens browser login if needed. If your account has multiple organizations, select one with `npx uivoid org use <slug>` or pass `--org <slug>`.

This creates a project on UIvoid and activates its hosted MCP gateway. The demo API deliberately accepts the outbound Authorization header generated by the CLI. That credential is shown once: keep it out of screenshots and recordings.

## 4. Ask your agent

Add the exact MCP URL returned by the CLI to a client with authenticated remote MCP support. Complete organization login, refresh its tools, and ask:

> Use list_products to find products with fewer than 5 units in stock. Show their names and stock counts.

Expected answer after a successful tool call: **Pencil: 3; Backpack: 0.** Inspect the client's tool trace to verify it actually called `list_products`.

Then ask:

> Use get_product with id notebook. How many are in stock?

Expected answer: **12**.

If a call fails, check the public API URL, the active project in the [portal](https://portal.uivoid.app), organization login, and tool availability. A created project alone does not prove a successful client connection.

## Record a short demo

Capture the create command, the returned MCP URL, and the first agent tool call. Crop or redact tokens, credentials, personal information, and browser login. Label cuts or speedups; measure setup time before making a timing claim. Use the actual successful run for a GIF or video.

When finished, remove the demo project through the portal and shut down the API deployment or tunnel.
